# Vectors from Zero

## Objective

Understand vectors as quantities with both size and direction, then use components to describe motion, force, and position changes.

## Why It Matters

Robots, drones, physics, computer vision, and GIS all use vectors. A drone velocity, a robot movement command, a force, and a GPS displacement all have direction as well as magnitude.

## Concept

A scalar has size only:

$$speed = 5m/s$$

A vector has size and direction:

$$velocity = 5m/s\ east$$

In 2D, a vector can be written with components:

$$\vec{v} = (v_x, v_y)$$

The magnitude is:

$$|\vec{v}| = \sqrt{v_x^2 + v_y^2}$$

## Worked Example

A robot moves `3 m` east and `4 m` north. Its displacement vector is:

$$\vec{d} = (3, 4)$$

The magnitude is:

$$|\vec{d}| = \sqrt{3^2 + 4^2} = 5m$$
