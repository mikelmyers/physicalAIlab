# Graphing Functions for Builders

## Objective

Read and sketch graphs as visual stories about how one quantity changes with another.

## Why It Matters

Graphs show sensor calibration, battery discharge, motor response, altitude over time, error in a control loop, and simulation results. You need to read them like technical evidence.

## Concept

A function connects an input to an output:

$$output = f(input)$$

For example, position as a function of time can be written:

$$x = f(t)$$

The horizontal axis usually shows the input. The vertical axis usually shows the output.

Slope describes rate of change:

$$slope = \frac{change\ in\ output}{change\ in\ input}$$

For a position-time graph, slope is speed.

## Worked Example

A robot position changes from `2 m` at `1 s` to `8 m` at `4 s`.

The slope is:

$$slope = \frac{8m - 2m}{4s - 1s}$$

$$slope = \frac{6m}{3s} = 2m/s$$

The robot's average speed is `2 m/s`.
