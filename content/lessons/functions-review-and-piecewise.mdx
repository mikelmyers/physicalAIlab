# Functions Review and Piecewise Definitions

## Re-entry Promise

This lesson assumes you have seen function notation before, but it does not assume you are fluent with it. If $f(x)$ still feels like a weird decoration instead of a machine with inputs and outputs, that is exactly what this lesson is here to fix.

Pre-calculus begins by making functions feel operational. A function is not just a graph in a textbook. It is a rule for turning inputs into outputs: sensor voltage into distance, time into position, motor command into speed, image brightness into a thresholded label, battery state into allowed power.

By the end, you should be able to read, evaluate, graph, and build functions that change rules depending on the input.

## Plain-Language Intuition

A function is an input-output promise.

If you give the function an allowed input, it gives back one output. Not zero outputs. Not two different outputs for the same input. One.

Examples:

- A temperature sensor function maps voltage to temperature.
- A robot path function maps time to desired position.
- A controller function maps error to motor command.
- A camera threshold function maps pixel brightness to black or white.
- A safety limiter maps requested speed to allowed speed.

Piecewise functions appear when one rule is not enough. Many real systems behave differently in different regions. A motor might be off below a deadband, proportional in the middle, and saturated at high command. That is a piecewise function.

## Why This Idea Exists

Functions let humans describe change without listing every possible input. Instead of writing a million sensor readings, we write a rule. Instead of storing every point on a trajectory, we write a formula. Instead of explaining a controller with paragraphs, we write a function.

Piecewise functions exist because the world has regimes:

- Below a threshold, nothing happens.
- Above a limit, hardware saturates.
- Before a switch time, one behavior applies.
- After contact, a robot changes mode.
- Inside a safe region, control is normal.
- Outside a safe region, emergency behavior takes over.

Calculus studies how functions change. Before calculus can make sense, functions themselves must be solid.

## Core Theory

### Function Definition

A function $f$ from a domain $D$ to a range of possible outputs assigns each input $x$ in $D$ exactly one output $f(x)$.

The notation:

$$
f(x)=2x+3
$$

means: give the function an input $x$, multiply by 2, add 3, and return the result.

### Input And Output

In $y=f(x)$:

- $x$ is the independent variable.
- $y$ is the dependent variable.
- $f$ is the rule.
- $f(x)$ is the output when the input is $x$.

If $h(t)$ gives a drone altitude at time $t$, then time is the input and altitude is the output.

### Domain

The domain is the set of allowed inputs.

Engineering domain restrictions often come from physical meaning:

- Time after launch: $t\ge0$.
- Battery percentage: $0\le p\le100$.
- Distance from a sensor: $d\ge0$.
- Denominators cannot be zero.
- Square roots of real quantities require nonnegative input.

### Range

The range is the set of outputs the function actually produces.

If a motor command is clipped between -1 and 1, its range is:

$$
[-1,1]
$$

even if the requested command can be larger.

### Evaluating Functions

To evaluate $f(4)$ for:

$$
f(x)=2x+3
$$

replace every $x$ with 4:

$$
f(4)=2(4)+3=11
$$

### Function From A Table

A table can define a function if each input appears with only one output.

| input | output |
| --- | --- |
| 0 | 2 |
| 1 | 5 |
| 2 | 8 |

This table defines a function. Input 1 has one output: 5.

If input 1 appeared once with output 5 and again with output 9, the table would not define a function.

### Piecewise Function

A piecewise function uses different formulas for different parts of the domain.

Example:

$$
f(x)=
\begin{cases}
0, & x<0\\
2x, & 0\le x\le 5\\
10, & x>5
\end{cases}
$$

Read it as:

- If $x<0$, output 0.
- If $0\le x\le5$, output $2x$.
- If $x>5$, output 10.

### Interval Conditions

The condition chooses the rule. Always decide the interval before substituting.

For the function above:

$$
f(-3)=0
$$

because $-3<0$.

$$
f(4)=2(4)=8
$$

because $0\le4\le5$.

$$
f(8)=10
$$

because $8>5$.

### Step Functions

A step function jumps between values. Example:

$$
s(x)=
\begin{cases}
0, & x<3\\
1, & x\ge3
\end{cases}
$$

This models switches, thresholds, digital signals, and simple classifiers.

### Saturation Function

A saturation function limits output:

$$
\operatorname{sat}(u)=
\begin{cases}
-1, & u<-1\\
u, & -1\le u\le1\\
1, & u>1
\end{cases}
$$

This is a realistic actuator model. A motor command may request 1.4, but the hardware can only accept 1.

### Deadband Function

A deadband ignores small input:

$$
d(e)=
\begin{cases}
0, & |e|<0.1\\
e, & |e|\ge0.1
\end{cases}
$$

This appears in joysticks, noisy sensors, and control systems.

## Visual Or Mental Model

Think of a function as a machine with one input slot and one output slot. A piecewise function is the same machine with a decision gate at the front.

The decision gate asks: "Which interval is this input in?"

Only after that do you apply the formula.

For graphs, imagine drawing each rule only on its allowed interval, then stitching the pieces together.

## Worked Examples

### Example 1: Evaluate A Formula

Let:

$$
f(x)=x^2-3x+2
$$

Find $f(5)$.

$$
f(5)=5^2-3(5)+2=25-15+2=12
$$

### Example 2: Domain Restriction

Let:

$$
g(x)=\frac{1}{x-4}
$$

The denominator cannot be zero, so:

$$
x\ne4
$$

Domain: all real numbers except 4.

### Example 3: Evaluate A Piecewise Function

Let:

$$
p(x)=
\begin{cases}
x+2, & x<1\\
3x, & 1\le x<4\\
12, & x\ge4
\end{cases}
$$

Find $p(0)$, $p(2)$, and $p(6)$.

$$
p(0)=0+2=2
$$

$$
p(2)=3(2)=6
$$

$$
p(6)=12
$$

### Example 4: Saturated Motor Command

A motor limiter is:

$$
L(u)=
\begin{cases}
-1, & u<-1\\
u, & -1\le u\le1\\
1, & u>1
\end{cases}
$$

Then:

$$
L(0.4)=0.4
$$

$$
L(2.3)=1
$$

$$
L(-1.8)=-1
$$

### Example 5: Deadband

A joystick deadband is:

$$
J(u)=
\begin{cases}
0, & |u|<0.05\\
u, & |u|\ge0.05
\end{cases}
$$

If $u=0.03$, output is 0. If $u=-0.2$, output is -0.2.

### Example 6: Function Or Not?

Table A:

| input | output |
| --- | --- |
| 0 | 1 |
| 1 | 3 |
| 2 | 5 |

Function: yes.

Table B:

| input | output |
| --- | --- |
| 0 | 1 |
| 1 | 3 |
| 1 | 8 |

Function: no. Input 1 has two outputs.

### Example 7: Piecewise Graph

For:

$$
h(x)=
\begin{cases}
0, & x<0\\
x, & 0\le x\le3\\
3, & x>3
\end{cases}
$$

The graph is flat at 0 before the origin, rises with slope 1 from 0 to 3, then stays flat at 3. This is a ramp with saturation.

### Example 8: Mode Switch

A robot speed rule is:

$$
v(d)=
\begin{cases}
0, & d<0.2\\
0.5d, & 0.2\le d<2\\
1, & d\ge2
\end{cases}
$$

Here $d$ is distance to target.

- Very close: stop.
- Medium distance: slow proportional approach.
- Far away: maximum speed.

That is a practical control rule, not just a classroom function.

## Engineering Connections

### Control Saturation

Actuators have limits. A controller may compute a command outside the hardware range, but the actual output is clipped. Saturation is piecewise.

### Sensor Thresholding

A camera threshold maps brightness to black or white. A proximity sensor may map distance to "safe" or "too close." These are step functions.

### Robot Modes

A robot can use one rule while approaching a waypoint, another while docking, and another during emergency stop. Mode logic is piecewise behavior.

### Battery Management

Power limits may depend on battery temperature and charge level. Below a threshold, the system derates.

### Simulation

Physics engines often use piecewise rules: free motion before contact, collision response after contact.

## Common Failure Modes

1. Substituting into the wrong branch.
2. Ignoring whether an endpoint is included.
3. Treating $f(x)$ as multiplication by $f$.
4. Forgetting that one input must have exactly one output.
5. Confusing domain with range.
6. Claiming a vertical line graph is a function.
7. Graphing a piece beyond its allowed interval.
8. Using a formula outside its physical domain.
9. Forgetting units on input or output.
10. Assuming a piecewise function must be continuous.
