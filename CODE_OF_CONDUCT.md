# Code of Conduct

Physical AI Lab should remain a serious, respectful place for technical learning and open-source collaboration.

## Expected Behavior

- Be clear, constructive, and specific.
- Respect different experience levels.
- Critique ideas and implementation details, not people.
- Keep discussions focused on learning, building, and improving the project.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Publishing private information without permission.
- Repeated off-topic disruption.
- Bad-faith contributions or intentionally misleading technical content.

## Enforcement

Project maintainers may remove comments, close issues, reject pull requests, or block contributors when behavior undermines a safe and useful technical environment.
